# Politique de sécurité

## Versions supportées

Ce projet n'a pas encore de ligne de version stable. Seuls la branche `main`
et le dernier tag publié sont supportés ; les correctifs de sécurité visent
la version publiée la plus récente.

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique** pour une vulnérabilité.

Utilisez le signalement privé de GitHub :

1. Onglet **Security** du dépôt → **Report a vulnerability**.
2. Décrivez le problème : étapes de reproduction, impact si connu.

Nous accuserons réception et travaillerons avec vous sur un correctif et un
calendrier de divulgation. Pas de délai contractuel : le projet est maintenu
par une seule personne.
